## Responsible-use boundaries

- Use fictional workforce data and clearly attribute its source.
- Present aggregate associations, with sample sizes and small-group safeguards.
- Do not produce individual risk scores, employee rankings, or automated employment decisions.
- Do not invent causal explanations, historical trends, currency units, test results, or user feedback.
